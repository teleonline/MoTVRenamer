## MoTV Renamer 1.0.0

**Español**
Primera versión. Renombrador **gratuito** de películas y series para Windows, solo para **uso personal, no comercial**.

- Descarga `MoTVRenamer.exe` (abajo, en *Assets*) y ábrelo: no necesita instalación.

- Usa TMDb, OMDb, TheTVDB e IMDb. Interfaz en inglés y español, modo oscuro y claro.

**English**
First release. **Free** movie and TV series renamer for Windows, for **personal, non-commercial use** only.

- Download `MoTVRenamer.exe` (below, under *Assets*) and run it: no installation needed.
- Three steps: add files, find names and rename (can be undone).
- Uses TMDb, OMDb, TheTVDB and IMDb. English and Spanish interface, dark and light mode.

**Verification**
- SHA-256: `34c89adb287dab2d88d359e46b6a866718618ac1f0c6a7973a40ee88be8938aa`
